Healthcare Analysis Dashboard

📊 Project Overview

The Healthcare Analysis Dashboard is an Excel-based data analytics project created to transform healthcare data into meaningful insights through data cleaning, analysis, and visualization.

The project demonstrates practical skills in Microsoft Excel, data analysis, and dashboard development.

🎯 Project Objectives

* Clean and prepare healthcare data for analysis
* Explore and analyze key healthcare metrics
* Identify meaningful trends and patterns
* Create interactive visualizations
* Develop an easy-to-understand Excel dashboard
* Present insights in a clear and meaningful way

🛠️ Tools & Skills
